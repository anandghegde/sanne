# Sanne 0.2.0

BTT / Multitouch parity release: free-space trackpad gestures, tip-tap, Magic Mouse 3-finger swipes,
custom scripts, per-app gesture bindings, and an on-screen action HUD. New gestures ship **off by
default** so existing setups keep working until you enable them.

## Highlights

- **Free-space 3F/4F swipes + 4F tap** on the trackpad (opt-in; turn off the matching System Settings gestures first)
- **Tip-tap** left / right (hold one finger, tap beside it)
- **Magic Mouse 3-finger swipes** L/R/U/D (travel vs. middle-click on the same chord)
- **Custom script actions** — shell, AppleScript, or Shortcuts; 10 s timeout; concurrency cap
- **Per-app gesture bindings** — same gesture, different action per frontmost app
- **Action name overlay (HUD)** — brief label when a gesture fires (off for plain clicks / continuous drags)
- Illustrated gesture diagrams + System Settings-style sidebar polish
- Magic Mouse hover/ghost-click fixes

## Install

1. Open `Sanne-0.2.0.dmg`
2. Drag **Sanne** to **Applications**
3. Open Sanne
4. Enable **Accessibility** for Sanne  
   System Settings → Privacy & Security → Accessibility

If you are upgrading from 0.1.0, your existing `config.json` loads unchanged. Enable the new
gesture groups under Settings → Trackpad / Magic Mouse when you want them.

## Requirements

- macOS 13 Ventura or later
- Magic Mouse and/or Multi-Touch trackpad recommended

## Checksum

See `Sanne-0.2.0.dmg.sha256` next to the DMG on the release assets.

## Known limitations

- New free-space / tip-tap / Magic Mouse 3F paths have unit coverage for pure logic; full hardware QA on real devices is still recommended before wide distribution
- Build may be Developer ID signed and/or notarized depending on the channel; ad-hoc builds need a manual Accessibility grant
- No custom app icon yet
- Report issues with macOS version, devices, and a snippet from  
  `~/Library/Logs/Sanne/sanne.log`
