# Sanne 0.1.0

First private-beta / MVP build.

## Highlights

- Magic Mouse silent taps (left / right / middle, multi-click, tap-drag)
- Titlebar window snaps (halves, thirds, quarters, maximize, minimize, pinch)
- Dock & menu bar zone gestures
- Keyboard snap (⌃⌥) and modifier-drag move/resize
- Full gesture remap: catalog actions, **recorded keystrokes**, **open app**
- Per-app pause rules, import/export, tutorial & cheat sheet

## Install

1. Open `Sanne-0.1.0.dmg`
2. Drag **Sanne** to **Applications**
3. Open Sanne
4. Enable **Accessibility** for Sanne  
   System Settings → Privacy & Security → Accessibility

## Requirements

- macOS 13 Ventura or later
- Magic Mouse and/or Multi-Touch trackpad recommended

## Checksum

See `Sanne-0.1.0.dmg.sha256` next to the DMG on the release assets.

## Known limitations

- Build may be ad-hoc signed if not notarized for this channel
- No custom app icon yet
- Report issues with macOS version, devices, and a snippet from  
  `~/Library/Logs/Sanne/sanne.log`
